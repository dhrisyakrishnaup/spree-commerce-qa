# Spree Commerce QA Testing

## Project Overview

This project demonstrates practical QA testing of an e-commerce web application using Selenium with Python and PyTest.

The project was completed as a practical Software Testing assignment.

## Testing Activities

* Web application testing
* Product selection and validation
* Cart-related testing
* Test execution and result validation
* Web automation using Selenium
* Automated test execution using PyTest

## Automation

Selected test scenarios were automated using:

* Python
* Selenium WebDriver
* PyTest

## Tools Used

* Python
* Selenium
* PyTest
* PyCharm
* Git
* GitHub
